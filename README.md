# Doner Club — визуальный гид

Репозиторий для версии сайта `brand.donerclub.kz`, перенесённой из ChatGPT Sites в обычный GitHub-проект.

## Структура

- `index.html` — главная страница визуального гида
- `gallery.html` — полная галерея материалов
- `assets/` — изображения, PDF, видео и фирменные материалы
- `styles/` — стили
- `scripts/` — интерактивность

## Домен

Целевой домен: `brand.donerclub.kz`

## Статус миграции

Исходный проект ChatGPT Sites найден и зафиксирован. Следующий этап — перенос визуальной разметки и всех медиа-материалов в этот репозиторий без изменения содержания сайта.
