# Doner Club — визуальный гид

Репозиторий для версии сайта `brand.donerclub.kz`, перенесённой из ChatGPT Sites в обычный GitHub-проект.

## Структура

- `dist/index.html` — главная страница визуального гида
- `dist/gallery.html` — полная галерея материалов
- `dist/strategy/` — презентация стратегии (20 слайдов)
- `dist/assets/`, `dist/docs/` — изображения, документы и видео
- `dist/styles.css`, `dist/script.js` — оформление и интерактивность гида

## Домен

Целевой домен: `brand.donerclub.kz`

## Локальный запуск

Сборка и установка зависимостей не нужны. Из корня репозитория:

```sh
python -m http.server 8766 --bind 127.0.0.1 --directory dist
```

Открыть `http://127.0.0.1:8766/strategy/` или главную страницу сервера.
Render публикует каталог `dist` из ветки `main`.

Презентация использует единые внешние CSS и JavaScript. На мобильных устройствах
слайды прокручиваются вертикально, широкие схемы — горизонтально внутри рамки.
Пути ресурсов начинаются с `/strategy/`, чтобы адреса `/strategy` и `/strategy/`
работали одинаково. При изменении оформления обновляйте версию ресурсов в HTML.
